## 🧩 Overview
Analyzed a dataset of 1,026 customers to identify key factors influencing bike purchases.  
Built an interactive Excel dashboard to explore how demographic and behavioral variables impact buying decisions.

## 🧹 Data Preparation
- Cleaned and structured 1,000+ rows of data  
- Removed duplicates and handled missing values  
- Standardized key fields (age groups, education, region)  
- Applied Excel functions (IF, INDEX-MATCH) for transformation  

## 📈 Key Insights
- 🎯 Customers aged **30–45** have the highest purchase rate (~56%)  
- 🚴 **2–5 mile commute** customers are most likely to buy  
- 📉 Income has moderate impact; **commute distance is a stronger driver**  
- 🧠 Occupation and car ownership further influence purchasing behavior  

## 📊 Dashboard Features
- 🎛️ Filters: Marital Status, Region, Education  

- 📌 KPIs:
  - Total Customers: **1,026**  
  - Purchase Rate: **48%**  
  - Top Age Group: **30–45**  
  - Best Commute Range: **2–5 miles**  

- 📉 Analysis:
  - Income vs Purchase  
  - Age Group Analysis  
  - Commute Distance Analysis  
  - Car Ownership Analysis  
  - Occupation Analysis  
  - Home Ownership Analysis  

## 🧠 Business Value
Identifies high-conversion customer segments.  
Enables targeted marketing toward **middle-aged customers with moderate commute distances** to improve conversion rates.
